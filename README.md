# Besafe Tech Website Redesign (v2)
**Project Framework:** PRINCE2
**Technology Stack:** Next.js, TypeScript, Tailwind CSS

## 1. Documentation: The Old Site (besafe-tech.com)
* **Status:** Current Production.
* **Gaps:** Static content, no user interaction, limited lead qualification.
* **Risk:** Potential customers leave without a clear "call to action."

## 2. Documentation: The New Site (Prototype)
* **Objective:** Create a High-Trust Lead Generation Hub.
* **Proposed Features:**
    * **Assessment Tool:** Interactive security quiz for potential clients.
    * **Localization:** Full Arabic/English support for KSA/UAE markets.
    * **Client Transparency:** Integrated portal for viewing security reports.
